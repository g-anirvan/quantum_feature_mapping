# quantum_feature_mapping
Quantum feature mapping for nonlinear time-series prediction using Qiskit and Python
# Quantum Feature Mapping for Chaotic Time-Series Prediction

## Overview

This project explores the use of quantum feature mapping for one-step-ahead prediction of a nonlinear time series generated by the logistic map.

A parameterized four-qubit quantum circuit is simulated using Qiskit. Computational-basis probabilities are extracted as features and supplied to a classical Ridge regression model.

## Objectives

- Generate a chaotic time series using the logistic map.
- Encode classical data into a parameterized quantum circuit.
- Extract quantum measurement probabilities as machine-learning features.
- Evaluate prediction performance using RMSE.
- Compare the quantum-feature model with classical regression baselines.

## Methodology

1. Generate 600 time-series samples using the logistic map with parameter r = 3.9.
2. Encode each input into a four-qubit circuit using parameterized Ry rotations.
3. Apply an entangling layer of CNOT gates.
4. Simulate the circuit and extract 16 computational-basis probabilities.
5. Train a Ridge regression model to predict the next time-series value.
6. Compare its performance with classical quadratic regression and a naive persistence baseline.

## Initial Results

| Model | RMSE |
|---|---:|
| Quantum-feature regression | 0.065955 |
| Classical quadratic regression | Approximately 0 |
| Naive persistence baseline | 0.531328 |

## Interpretation

The quantum-feature model outperforms the naive persistence baseline in this experiment. However, classical quadratic regression reproduces the underlying logistic-map relationship almost exactly because the data-generating equation is quadratic.

These results do not establish quantum advantage. The current implementation is a quantum feature-mapping experiment rather than a full dynamical quantum reservoir with temporal memory.
